# Monorepo Project

This is a monorepo containing multiple applications:

## Applications

### Web App (`apps/web/`)
- React application with Vite
- UI components using shadcn/ui
- Tailwind CSS for styling

### API Server (`apps/api/`)
- Node.js/Express API
- PocketBase integration for database

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

### Start Production
```bash
npm start
```
